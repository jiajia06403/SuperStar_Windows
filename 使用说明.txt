SuperStar · 学习通刷课
========================================

【重要】本程序按「整个文件夹」分发
  它需要和同一个文件夹里的 runtime\、config_win.ini 一起使用。
  - 请把压缩包【完整解压】到一个文件夹（Windows 右键「全部提取」会按压缩包名自动建好文件夹），
    再双击文件夹内的主程序（SuperStar.exe）；
  - 不要在压缩包预览窗口里直接双击运行，也不要只把 exe 拷到别处
    （只拷 exe 会报「Failed to load Python DLL」直接起不来；
     即使把整个文件夹拷走，题库配置与进度缓存也会丢，等于从零开始）；
  - runtime\ 是程序运行时文件（Python 与各种依赖库），不能删、不能改名；
  - 换电脑或移动位置时，请连同整个文件夹、以及运行后自动生成的 config_user.ini 一起复制；
  - 升级新版本时，建议先删掉旧文件夹再解压新包（避免旧文件残留）。

文件夹内容
  SuperStar.exe  主程序（文件名不带版本号，版本体现在压缩包名上）
  runtime\        程序运行时文件（Python 与依赖库，exe 启动必需，勿删）
  config_win.ini       默认配置（随包自带，升级会被覆盖 —— 不要改它）
  config_user.ini      用户配置（首次启动自动生成，升级不覆盖 —— 要改就改这里）
  chaoxing.log         运行日志（首次启动自动创建，可随时删除）
  progress_cache\      进度缓存 / 已保存账号 / cookies / 本地题库（首次启动自动创建，按课程自动写入）
  使用说明.txt          本文件
  LICENSE              开源协议（GPL-3.0）

使用步骤
  1. 点「添加账号」登录（或勾选 cookies 登录，cookie 文件为 progress_cache\cookies.txt）；
  2. 左侧点击课程名勾选要刷的课（可「全选」）；
  3. 调整倍速/并发（默认 2.0 倍速 / 4 并发），点「开始刷课」，右侧看章节进度，底部看日志。
     章节测验被判「不合格」会自动重答（默认 3 次）；若因此导致下一章一直未开放，
     程序会回退重做上一章并**无限重答**，直到平台判通过或你点「停止」。

进度缓存
  progress_cache\<uid>.json 按账号保存已完成章节，删除该文件即重新刷该账号。
  换电脑或挪动位置时，请把整个文件夹一起复制（不要只拷 exe，也不要删 runtime\）。

可选配置（题库 / 通知）
  配置文件有两份，分工固定：
    config_win.ini    默认配置：随包分发，升级解压时会被覆盖 —— 请不要改它；
    config_user.ini   用户配置：首次启动由默认配置生成，升级不覆盖 —— 要改就改这里。
  生效规则：默认配置打底，用户配置逐键覆盖（用户留空也算覆盖，可用来停用题库）。
  升级后程序会自动拿新的默认配置校验用户配置：新增项按默认值补齐、
  已移除的项转入 [obsolete] 段保留、取值非法则回落默认值，日志里会写明。
  不配置则题库停用，只完成视频、文档、阅读等任务点。
  题库设置：「答案提供方式」下拉里选哪一种，下面的可填项就只显示那一种需要的
  （言溪/LIKE 填 TOKEN、TikuAdapter 填服务地址、大模型填接口地址 + API Key + 模型）；
  AI / DeepSeek / SiliconFlow 三套大模型配置各存各的，切换时自动带出各自的默认
  地址与模型，一般只要补 API Key 即可。下拉就放在「专属设置」正上方。
  答题一律提交（界面已无「提交答题」开关）；判断题的正确/错误词表也不再提供
  输入框，固定用默认值（需要自定义时改 config_win.ini 的 true_list / false_list）。

界面主题（浅色 / 深色 / 跟随系统）
  工具栏「设置」->「外观」->「主题」，三选一：
    跟随系统  随 Windows 的深色/浅色设置自动切换（默认）；系统一改，界面几秒内跟着变，
              标题栏与窗口圆角用 Win11 原生样式；
    浅色 / 深色  固定，不随系统切换。
  也可以直接改 config_user.ini 的 [ui] theme（system / light / dark），下次启动生效。

视频学习：观看进度要求 + 状态日志
  工具栏「设置」->「视频学习」里有两项，都写进 config_user.ini 的 [common] 段：
    video_finish_percent  观看进度要求（90~100，默认 90）
      播到该百分比即判定这个视频任务点完成，不必全部看完，剩下的时长不再干等。
      取 100 = 旧行为：必须完整看完，并且要等平台返回「已通过」；
      取 90~99 = 看到该比例并上报一次后，平台仍未判通过就按本规则判定完成。
      允许范围就是 90~100：低于 90 收敛为 90、高于 100 收敛为 100，
      非整数（如 99.5）或非数字视为非法，回落默认 90。
    video_log_interval    状态日志间隔（秒，默认 10，0 = 不输出）
  状态日志行形如：
    视频进度 | 45.2% (812/1800s) | 剩余约8分14秒（2x） | 章节 3/12《第二章 导数与微分》 | 任务 1.1 导数的定义
  依次是：进度百分比（已播/总时长）、按真实时间估算的剩余、章节号与章节名、视频名。
  两项保存后即时生效，正在刷课也作用于当前视频循环，不用重启。

本地题库（只存正确答案，按课程共享，重做/换账号直接读）
  作业提交成功后，程序会再读一次作答页核对：
    - 判对 -> 把本次答案存下来（它就是正确答案）；
    - 判错但页面上有「正确答案」-> 把正确答案存下来（下次直接答对）；
    - 判错且拿不到正确答案、或还没批阅 -> 不收录（题库里只有正确答案，绝不猜）；
    - 题库里已有的答案与平台给的一致 -> 跳过不写（不重复写）；
    - 题库里已有的答案与平台给的**不一致** -> 覆写纠正
      （典型场景：上次用题库答案作答被判错，说明库里那条是坏的，这次用正确答案改掉）。
  之后重做同一份作业、或换另一个账号做同一门课时，搜题会先查本地题库，
  命中就用，不再消耗题库/大模型额度。每次提交后都会核验一次判分（只为发现答错的题，
  不核验就永远不知道库里的答案是错的）。
  - 同一门课的题目和答案对所有账号都一样，所以题库只按课程存放，所有账号共用：
      progress_cache\local_bank\<课程ID>.json
    例如 progress_cache\local_bank\高等数学_246831735.json
  - 换账号做同一门课直接命中同一个文件（不再按账号建文件夹，也不用重复采集）；
  - 选项顺序变了也能对上（按选项文字重新定位），文字被改写则宁可不答；
  - 旧结构启动时自动迁移：初版 local_bank.json、上一版的 <账号>\<课程>.json
    都会合并进课程文件，旧目录改名为 .migrated 保留（不删数据）；
  - 开关（写进 config_user.ini 的 [tiku] 段）：
      local_bank=true         总开关，false = 完全不读不写本地题库
      local_bank_verify=true  提交后核验判分（补缺失 + 纠正答错的题）；界面上已与
                              「启用本地题库」合并，保存时自动跟它同步
                              （开题库 = 核验，关题库 = 只读不写）
      local_bank_dir=         题库根目录，留空 = progress_cache\local_bank
  - 管理：设置 →「本地题库…」可查看统计、导出、导入合并、打开目录、清空；
    导入合并时同题保留确认次数更多的答案；导入前建议先导出一份备份。
  - 导出的 JSON 包按课程分文件，别人导入后会自动还原，也可以直接把整个
    local_bank 文件夹拷给别人用。
  - 老配置里的 local_bank_trust（收录未核验答案）已移除，升级时该键会自动
    移到 [obsolete] 段，不影响其他设置。

从已完成账号采集答案（不用重做作业）
  已经刷完课的账号，作业页就是成绩页：每题带着对错、「正确答案」和「我的答案」。
  - 主界面勾选课程 -> 点「采集题库」-> 确认，后台会逐章读历史作业，把正确答案存进
    课程题库文件（local_bank\<课程ID>.json）。只读：不提交、不保存草稿。
  - 收录口径：有「正确答案」就存正确答案；只判对不公布答案的，存「我的答案」；
    判错又没答案、未批阅、作业已关闭的，一律跳过（不猜）；
    题库里已有的答案与页面一致就跳过，不一致则用页面答案覆写纠正。
  - 只对「已提交」的作业有效：没交过的作业页只有作答区，没有答案可采，日志里记为
    「未提交」。所以先刷课（刷课时会提交章节测验）或自己交一遍，再来采集。
  - 采集结束的提示会分开写明「未提交 / 未批阅 / 无法识别」各多少份。
    只有「无法识别」说明页面结构没认出来，这时原始页面会存到
    progress_cache\collect_debug\，日志里有路径，反馈问题时发那个文件即可。
  - 章节多的课要几分钟，日志里会显示进度；中途点「停止」可中断，已采集的部分保留。
  - 命令行（需先在界面登录过一次，凭据已加密保存在本机）：
      python -m api.collect                         采集全部课程
      python -m api.collect --course 高等数学,247100002   按标题关键词或 courseId 过滤
      python -m api.collect --max-works 3             只读 3 份作业试跑
      python -m api.collect --uid <uid>                指定已保存账号
  - 采集完换新账号做同一门课，搜题会直接命中这份题库，不用再花额度。

已知限制
  - 需联网并依赖超星服务端，账号异常/风控由平台判定；
  - 本程序仅供学习交流，请勿用于商业用途，使用后果自负。
