SuperStar · 学习通刷课
========================================

【重要】本程序按「整个文件夹」分发
  必须和同文件夹里的 runtime\、config_win.ini 一起使用，不要只把 exe 拷到别处
  （只拷 exe 会报「Failed to load Python DLL」起不来；只拷文件夹不带进度缓存等于从零开始）。
  - 压缩包【完整解压】到同一文件夹（Windows 右键「全部提取」会自动建好），双击文件夹内的 SuperStar.exe；
  - 不要在压缩包预览窗口里直接双击运行；
  - runtime\ 是运行时文件（Python 与依赖库），不能删、不能改名；
  - 换电脑/升级时连同整个文件夹一起复制（升级建议先删旧文件夹再解压新包，避免旧文件残留）。

文件夹内容
  SuperStar.exe  主程序（不带版本号，版本体现在压缩包名）
  runtime\        运行时文件（exe 启动必需，勿删）
  config_win.ini       默认配置（随包自带，升级会被覆盖 —— 不要改）
  config_user.ini      用户配置（首次启动生成，升级不覆盖 —— 要改就改这里）
  chaoxing.log         运行日志（首次自动创建，可随时删除）
  progress_cache\      进度缓存 / 账号 / cookies / 本地题库（首次自动创建）
  使用说明.txt          本文件
  LICENSE              GPL-3.0

使用步骤
  1. 点「添加账号」登录（或勾选 cookies 登录，cookies 文件为 progress_cache\cookies.txt）；
  2. 左侧点课程名「选中」要刷的课（单选：蓝底那行即当前选中）；
     刷课中不能切课（提示「刷课中不能切换课程」），换课请先「停止」再选另一门；
  3. 调倍速/并发章节（默认 2.0 倍速 / 1 并发章节），点「开始刷课」，右侧看章节进度、底部看日志。
     「并发章节」= 同门课同时刷几章；单章内任务点并发在「设置 → 视频学习 → 任务点并发」（默认 1）。
     刷课遇「章节未开放」本轮自动降为串行（并发 1）。
     章节测验判「不合格」自动重答（默认 3 次）；若导致下一章一直未开放，会回退重做上一章并无限重答，直到平台判通过或点「停止」。

进度缓存
  progress_cache\<uid>.json 按账号存已完成章节，删该文件即重刷该账号。

可选配置（题库 / 通知）
  配置分两份：config_win.ini（默认，升级覆盖，勿改）/ config_user.ini（用户，升级不覆盖，要改就改这里）。
  生效：默认打底，用户逐键覆盖（留空也算覆盖，可用来停用题库）；升级后用新默认配置校验用户配置
  （新项补默认、已移除项转入 [obsolete]、非法值回落默认，日志写明）。
  不配置则题库停用，只完成视频、文档、阅读等任务点。
  题库：「答案提供方式」下拉选一种，下方只显示该种需要的项
  （言溪/LIKE 填 TOKEN、TikuAdapter 填服务地址、大模型填接口地址 + API Key + 模型）；
  AI/DeepSeek/SiliconFlow 三套各存各的，切换自动带出默认地址与模型，一般只补 API Key。
  答题一律提交（无开关）；判断题词表固定用默认（自定义改 config_win.ini 的 true_list/false_list）。

界面主题（浅色 / 深色 / 跟随系统）
  设置 → 外观 → 主题：
    跟随系统  随 Windows 深浅色自动切换（默认），标题栏与窗口圆角用 Win11 原生；
    浅色 / 深色  固定，不随系统。
  也可改 config_user.ini 的 [ui] theme（system/light/dark），下次启动生效。

视频学习（设置 → 视频学习，写入 [common] 段，保存即时生效，刷课中也生效）
  video_finish_percent  观看进度要求（90~100，默认 90）
    播到该比例后开始「复查」：平台认可即结束；不认可则继续看 5 秒再上报，循环至判通过或整段看完。
    取 100 = 旧行为（从结尾每 5 秒复查）；低于 90 收敛为 90、高于 100 收敛为 100，非法回落 90。
  video_log_interval    状态日志间隔（秒，默认 10，0 = 不输出）
    日志行形如：视频进度 | 45.2% (812/1800s) | 剩余约8分14秒（2x） | 章节 3/12《第二章》 | 任务 1.1 导数的定义

本地题库（只存正确答案，按课程共享）
  作业提交成功后重读作答页核对：
    判对 → 存本次答案；判错但页面有「正确答案」→ 存正确答案；
    判错且拿不到答案或未批阅 → 不收录（绝不猜）；库里已有且与平台一致 → 跳过；不一致 → 覆写纠正。
  重做同一份作业或换账号做同门课，搜题先查本地题库命中即用，不再耗额度。
  按课程存放、全账号共用：progress_cache\local_bank\<课程ID>.json（如 高等数学_246831735.json）。
  选项顺序变了按文字重定位，文字被改写则宁可不答。
  旧结构启动时自动迁移（local_bank.json 与 <账号>\<课程>.json 合并进课程文件，旧目录改名 .migrated 保留）。
  开关（config_user.ini 的 [tiku] 段）：
    local_bank=true          总开关，false = 完全不读不写
    local_bank_verify=true   提交后核验判分（补缺失 + 纠正答错）；界面已与「启用本地题库」合并同步
    local_bank_dir=          题库根目录，留空 = progress_cache\local_bank
  管理：设置 →「本地题库…」可查看统计、导出、导入合并、打开目录、清空；导入合并时同题保留确认次数更多者，导入前建议先导出备份。
  导出 JSON 按课程分文件，别人导入自动还原；也可直接拷整个 local_bank 文件夹共享。
  老配置 local_bank_trust（收录未核验答案）已移除，升级时自动移入 [obsolete]。

从已完成账号采集答案（不用重做作业）
  已刷完课的账号作业页即成绩页，含每题对错、「正确答案」和「我的答案」。
  - 选中课程 → 点「采集题库」→ 确认，后台逐章读历史作业存进课程题库（只读，不提交/不存草稿）。
  - 收录：有「正确答案」存正确答案；只判对不公布答案存「我的答案」；判错无答案/未批阅/作业已关闭 → 跳过；库里已有与页面一致跳过，不一致用页面覆写纠正。
  - 只对「已提交」作业有效：没交过只有作答区，先刷课（会提交章节测验）或自交一遍再采。
  - 结束提示分开写明「未提交 / 未批阅 / 无法识别」各多少；只有「无法识别」会存原始页到 progress_cache\collect_debug\，反馈时发该文件。
  - 章节多的课要几分钟，日志显进度，中途「停止」可中断（已采集保留）。
  - 命令行（需先在界面登录过）：
      python -m api.collect                                  采集全部
      python -m api.collect --course 高等数学,247100002      按标题或 courseId 过滤
      python -m api.collect --max-works 3                    只读 3 份试跑
      python -m api.collect --uid <uid>                       指定已保存账号

已知限制
  - 需联网并依赖超星服务端，账号异常/风控由平台判定；
  - 仅供学习交流，请勿用于商业用途，使用后果自负。
